# full Attention＋MSEの雑談での反復観察（2026-11-14開始）

`distill-full-fsdp-20261110/step-0008062` で、状態を保持した雑談を実施した。
**172ターン・62,950生成tokensで停止。約6.1万生成tokens台で「光」と助詞・記号を
組み合わせた断片の反復が持続し、短い話題変更後も再発した。**
同一tokenを数百回連続する型ではない。全応答で同一tokenの最大連続は3回であり、
厳密な周期反復の閾値も超えていない。

早期から朝食・窓辺などへの内容の固着があり、実行中のユーザー指示
「内容の固着は許容し、同語連打が出るか10万生成トークンまで続ける」に従って継続した。
最後は朝食の描写などの文章よりも、ほぼ同じ語と助詞・記号を並べる出力になったため、
目視での反復判定と回復確認を経て終了した。10万生成tokensには未到達。
元モデルの設定上の65,536 tokensを超えて処理できたが、自然な会話の維持とは区別する。

## 条件

- full Attention、RoPEなし、CausalConv kernel4、LogKV C=4、BF16推論。
- 訓練の `hidden_mse_weight=0.1` をmanifestで確認。1 epoch・8,062 stepで完了したcheckpoint。
- 元モデルrevision: `7c19bc90e49b717381e4f474ee95964c05217a28`。
- medium / temperature0.8 / top-p0.95 / seed20261105、各応答上限2,048 tokens。
- LogKV状態を保持し、analysisも引き継ぐ。会話途中の状態リセットなし。
- 目標100,000生成tokens、最大7.5時間。生成数はanalysis・EOSを含み、入力・終端補完を除く。
- 既存 `scripts/run_dialogue_experiment.py` とChatEngine、ソースcommit `66a3705`。
- 主対象GPU 0。独立した短い新規セッションでの確認だけGPU 1を使用。
  GPU 5のユーザーのチャットサーバは変更していない。
- 相手役はCodex。初めは出力を読んで問いを書き、その後は自作の雑談質問をキューに追加して
  生成を監視。後半は話題の組と質問文型の組合せも使用。外部LLM APIは使用していない。
- 長期記憶の正答率を検査する課題は入れず、通常は食事・散歩・動物・趣味などの短い質問。

同一token64連続、または128 tokens以上を占める4回以上の周期的反復（周期128以下）を
機械的な候補とした。可変の記号・空白を含む反復も生出力から観察した。
最後の停止は機械的な閾値ではなく、同じ語の断片を並べ続ける文面と話題変更後の再発による
目視判定である。語の出現回数は事後的な記述値であり、事前に固定した停止閾値ではない。

## 経過と停止理由

| ターン | 観察 | 累計生成tokens |
|---|---|---:|
| 1 | 430 tokensでEOS終了。軽微な重複はあるが文章として応答 | 430 |
| 2〜13 | 別の話題でも朝食・コーヒー・窓辺へ戻る。13で明示的に猫へ話題変更しても固着 | — |
| 100〜104 | 101で「甘い」29回。短い犬の質問104でも固着するが、長い連打ではないため継続 | 104終了時14,607 |
| 136〜138 | 「Morning Light」の見出しと短い断片が増える。犬についての質問138でも逸脱するが、文章へ戻り540 tokensでEOS終了したため継続 | 138終了時33,599 |
| 168 | 「光」277回。後半に「光」と助詞・記号の断片が目立つ。状態累計65,536を通過 | 59,176→60,742 |
| 169 | 91 tokensの短い断片でEOS終了 | 60,742→60,833 |
| 170 | 「光」398回、1,795 tokens。ほぼ全体で同じ語と助詞・記号を並べる反復が持続 | 60,833→62,628 |
| 171 | 猫が箱に入るしぐさについて質問。`****` とEOSのみの3 tokens | 62,628→62,631 |
| 172 | 犬と散歩するなら公園か川沿いかを質問。同じ「光」の断片が再発し、319 tokensで手動中断。「光」68回 | 62,631→62,950 |

170ターン目の例（原文の一部）：

> 光だけ。
> 光。光光。  光、雨光。

> 光光を**光として**。**光**も、光が光（光）

172ターン目でも `**光**＝光    光は光。`、`**光は、光。**光、光**は、**光”。`
のような断片が続いた。171の空応答だけでは結論を出さず、172でも反復が戻ることを確認した。
「朝食の話を続ける」という内容の固着から、同じ語と可変の記号を並べ続ける状態へ進んだ
と判断して停止した。**連続する同一tokenは最大3回、厳密な周期候補は0件**であり、
以前の「団」435連続とは異なる型の反復である。

上の60,833は170ターン目の開始前の累計であり、反復が始まった最初のtoken位置ではない。
168などに前兆があるため、厳密な発症位置や統計的な耐久限界とは扱わない。
記号・空白だけの最長連続は24文字で、以前の空コードブロック反復とも異なる。

97ターンでHarmonyヘッダーなどが崩れて `parts=[]` になり、finalが空のターンは104あった。
文章を含む生出力も多いので、解析済みchannelだけを載せる `transcript.md` では不十分。
`raw-transcript.md`、各 `result.json` の `raw`、実token IDsを一次記録とする。
全入力IDsを復号し、実際の質問全文が含まれることを確認した。

## 新規セッションでの短い確認

主対話7ターン目と全く同じ動物の質問を、同じcheckpoint・生成設定の新規セッションへ入力。
主対話では55生成tokensで朝食・コーヒーの描写だったのに対し、新規セッションでは
264生成tokensで猫・ウサギ・ハムスターなど動物に関連する応答になった。
入力118 / 生成264 / 状態382 tokens。主対話の状態とは混ぜていない。
同じ初期seedでも主対話7ターン目とはRNG位置が異なる。履歴の有無による違いの1例であり、
固着の原因を断定する実験ではない。

## 以前のrank128との比較と制約

[以前のrank128実験](casual-dialogue-20261109.md)は16,773生成tokensまで継続し、
51・52ターン目で空のコードブロックなどの反復が持続して停止した。
今回は62,950生成tokensまで継続し、元のコンテキスト長も超えたが、早期から質問に追従せず、
後半は同じ語の断片を並べる反復へ進んだ。単純に「品質が改善」「反復しなくなった」とは言えない。

生成設定・最初の質問は同じだが、全質問列を一致させた比較ではない。
full/LoRA、RoPE、conv、MSE、訓練が異なり、各checkpointにつき1軌跡である。
chat templateの日付も今回と以前では異なる。停止は双方とも目視判定を含み、
MSE単独の因果効果や反復までの長さの改善倍率を測る比較ではない。
